# shipsafe-demo

A deliberately insecure sample app, used as the one-click demo for
[ShipSafe](https://github.com/Lalit-Rajpurohit/shipsafe).

Everything in here is the kind of thing an AI coding assistant leaves behind when nobody reviews
the output: a committed cloud key, an API key shipped to the browser, a package that does not exist
on npm, a pinned dependency with a known CVE, and infrastructure open to the whole internet.

**The credentials in this repo are fake and have never been valid.** Do not deploy this.
